## Defaults and upgrade behavior

The public quick start seeds a fresh independent profile and explicitly opts into its test-only grant/deposit. Existing profiles start paused unless explicitly resumed. It never resets journals, signer leases or existing explicit risk/goals. Defaults remain4CLC,30s minimum,22/game,498/process,$0.10/throw,$110/game,400CLC play reserve and separately protected source gas. Zero-reserve, accelerated cadence, large compute and research quotas are not release defaults. AI autoApply, automatic conversion, bonded confirmations and explorer publishing remain disabled for new profiles.

The source ZIP contains no node_modules, dist, data profiles, wallet files, API keys, machine-local funding proofs, raw signed journals, test-run pages, caches, desktop binaries or old desktop installer workflow. Existing advanced/local-chain CLI code and regression WASM artifacts are not a public deployment configuration. Runtime public pins remain in src/public-rc1/contract.ts; changing deployment requires a reviewed update.
